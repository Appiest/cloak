# Cloak

The pitch deck for Cloak, built as a page in this Next.js app instead of in slide software.

## Run it

```sh
npm install
npm run dev
```

Open http://localhost:3000/present.

## Presenting

- Right arrow, space or a click moves to the next beat. Left arrow goes back.
- F toggles fullscreen.
- The URL tracks where you are, so `/present?slide=2&beat=3` jumps straight there.

## Checks

```sh
npm run check   # typecheck, lint (including a complexity limit) and tests
```
